# 📝 Todo App

A clean and simple task management application built using **Flutter**.  
The app helps users manage daily tasks with an easy-to-use interface and smooth interactions.

---

## 🚀 Features

- ➕ **Add Tasks**
- ✏️ **Update & Edit Tasks**
- 🗑️ **Delete Tasks**
- 💾 **Local Storage Support** (tasks saved even after closing the app)
- 🎨 **Minimal & Clean UI**
- 📱 **Fully Responsive Layout**
- ⚡ **Smooth Animations**

---

## 🛠️ Technologies Used

- **Flutter**
- **Dart**
- **Local Storage (SharedPreferences / Hive)**  
- **Provider / State Management** (if used)
- **Custom Widgets**
